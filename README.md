# VisualShower

Простой локальный просмотрщик 3D-моделей на **Next.js + Three.js**. Интерфейс на русском, два режима осмотра: орбита и свободный полёт.

Интерфейс переработан по правилам [Hallmark](https://github.com/Nutlope/hallmark) в направлении Technical studio. Цвета, шрифты и размеры находятся в `src/app/tokens.css`, базовые правила в `src/app/base.css`, стили просмотра в `src/app/globals.css`. Сравнение до и после: `.hallmark/compare.html`.

## Запуск

Нужен Node.js **20.9 или новее**.

```sh
npm install
npm run dev
```

Откройте **http://127.0.0.1:3000**. Для запуска готовой сборки:

```sh
npm run build
npm start
```

## Открытие моделей

- **GLB** — модель, материалы, текстуры и первая анимация.
- **GLTF** — выберите `.gltf`, `.bin` и текстуры вместе. Можно перетащить папку целиком: пути к вложенным ресурсам сохранятся.
- **OBJ** — геометрия; материалы MTL не импортируются.
- **STL** — бинарный и текстовый варианты.

Используйте кнопку «Открыть модель» или перетащите файл в сцену. Открывается одна модель за раз. Масштаб и центр автоматически подстраиваются под камеру; исходный файл не меняется. При ошибке предыдущая модель остаётся в сцене.

Загруженные пользователем файлы не отправляются на сервер и хранятся в памяти вкладки. При открытии или обновлении страницы автоматически загружается стартовая модель `public/models/bsgno_threejs.glb`. Кнопка «Вернуть стартовую модель» снова открывает её после просмотра другого файла. Если стартовый файл недоступен, показывается встроенная демо-модель с сообщением об ошибке. Декодеры Draco и KTX2 копируются локально из Three.js при `npm install`, Meshopt включён в сборку. При запуске нет запросов к внешним CDN.

## Управление

| Действие | Клавиша / мышь |
| --- | --- |
| Включить орбиту | `1` |
| Вращать вокруг модели | ЛКМ + движение мыши |
| Сдвигать камеру | ПКМ + движение мыши |
| Менять масштаб | Колесо мыши |
| Включить полёт | `2`, затем нажмите на сцену |
| Двигаться в направлении взгляда | `W A S D` или стрелки |
| Подниматься / опускаться | `E` / `Q` |
| Лететь быстрее | `Shift` |
| Освободить курсор | `Esc` |
| Вернуть модель в кадр | `F` |
| Переключить сетку | `G` |
| Открыть подсказки | `?` |

На сенсорном экране: орбита — жестами; полёт — движение пальцем для осмотра и экранные кнопки для перемещения.

В боковой панели доступны три фона, сетка, каркас и автовращение. В панели сцены — сброс камеры, сохранение PNG и полноэкранный режим. При системной настройке уменьшения движения автовращение отключено.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

Тесты проверяют реальные загрузчики GLB, OBJ и STL, обработку повреждённых файлов, поиск ресурсов GLTF, нормализацию масштаба, кадрирование и направление полёта.

Нужен браузер с WebGL 2. Свободный полёт мышью использует Pointer Lock; открывайте приложение через локальный сервер, а не `file://`.
